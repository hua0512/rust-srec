# Release Notes

## `v0.8.0`

This release updates Windows desktop notifications for portable builds and makes notification test failures visible.

## Desktop notifications

- Windows portable builds now register their notification name and icon for the current user before sending notifications, without requiring an installer or administrator access. This addresses the missing application identity that prevented the **Test** button and regular event notifications from producing popups on systems where rust-srec had never been installed.
- Windows notifications use **Rust-Srec** as the visible application name. The internal application identifier and package name are unchanged.
- The desktop notification **Test** button now displays registration and submission errors instead of silently discarding them. Test notifications and regular event notifications use the same delivery path.

## Before you upgrade

- No configuration or database migration is required when upgrading from v0.7.0.
- Windows notification preferences and Do Not Disturb still apply. A successful submission does not guarantee a visible banner. After updating, use **Notifications → Desktop Notifications → Test** to check your system's behavior.
- The notification registration and icon remain in the current user's profile after the app exits, so moving the portable folder does not move the notification icon.
