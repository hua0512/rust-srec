# 录制引擎 {#引擎-engines}

首次录制可使用 Mesio。需要 FFmpeg 的容器或编码兼容性时选择 FFmpeg，需要 Streamlink 的下载行为时选择 Streamlink。FFmpeg 和 Streamlink 需安装在后端主机；Docker 镜像包含受支持的工具。

Streamlink 也可作为**提取器**，在下载前解析直播 URL。提取器和下载引擎可独立选择，详见[引擎与提取器设置](../reference/configuration-overrides.md#引擎与提取器选择)。

## 1. 引擎功能列表

|         功能          |                Mesio                 |                 FFMPEG                  |               STREAMLINK                |
| :----------------------: | :-----------------------------------: | :-------------------------------------: | :-------------------------------------: |
|       FLV 下载       |                  ✅                   |                   ✅                    |                   ❌                    |
|       HLS 下载       |        ✅ <br/>(多线程)        |                   ✅                    |         ✅ <br/>(多线程)         |
| 录制时长统计 | ✅ <br/>(不支持原始数据模式) |                   ✅                    |                   ✅                    |
|  下载码率统计  |                  ✅                   | ✅ <br/>(不支持 -f segmentation) | ✅ <br/>(不支持 -f segmentation) |
|    按大小分段     | ✅ <br/>(不支持原始数据模式) | ✅ <br/>(不支持 -f segmentation) |                   ✅                    |
|  按时长分段   | ✅ <br/>(不支持原始数据模式) |                   ✅                    |                   ✅                    |
|     下载格式      |           FLV, M3U8, TS, M4S          |         支持其他格式          |         支持其他格式          |
|    FLV 一致性修复      |             ✅ (推荐)                 |                   ❌                    |                   ❌                    |
|    HLS 一致性修复      |             ✅ (推荐)                 |                   ❌                    |                   ❌                    |
|        CPU 使用率         |                  最低                 |                   低                   |                   低                   |
|       内存使用率       |                  最低                 |                   低                   |                 中                  |

使用 Mesio 时，可按需启用 FLV 和 HLS 一致性修复，以使用修复和分段功能。它们不能恢复源站从未交付的媒体。

## 2. FLV 一致性修复

启用后，FLV 数据会在进入写入器前通过一条有序修复链。该链保留媒体载荷，主要修复容器层结构：

| 问题 | 流水线行为 |
| --- | --- |
| 缺少 FLV 文件头 | 在首个标签前插入有效文件头 |
| 视频或音频格式变化 | 开始写入新文件，并补充播放所需的文件头 |
| 视频数据乱序 | 在保持内存有界的前提下重排相邻标签 |
| 时间戳跳变或回退 | 调整时间戳以保持播放连续性 |
| 重复媒体标签或序列头 | 启用对应选项时过滤 |
| 达到文件大小或时长限制 | 视频在关键帧边界轮换，仅音频输出则在下一个标签轮换 |
| FLV 统计与快速定位索引 | 在文件关闭前更新元数据 |

元数据更新不会重写已经完成的媒体数据。如果可用元数据空间不足，会缩短可选的快速定位索引。带过滤或加密标记的脚本载荷保持不变。

## 3. 原始数据模式 (Raw Data Mode)

在原始数据模式下，**Mesio** 引擎会将从网络接收到的流数据直接写入磁盘，不解析或处理媒体包（头信息、帧、元数据）。

### 主要特点：
- **减少处理开销**：跳过包解析和重封装可降低 CPU 和内存占用。
- **适用场景**：高带宽流或资源受限的环境（如入门级 NAS 或 VPS）。仅在网络稳定且 CDN 或流来源不会变更媒体头部等流结构时使用。

### 局限性：
由于不检查包结构，启用原始数据模式时，以下高级功能将无法使用：
- **数据统计**：无法实时计算录制时长和下载码率统计。
- **自动分段**：引擎无法检测帧边沿或时长，因此无法按大小或时长进行精确分段。
- **修复功能**：无法应用 FLV 一致性修复或 HLS 一致性修复，因为这些功能需要包级别的操作。

## 4. HLS 一致性修复 (Mesio 独占)

Mesio 的 HLS 下载反应堆与 HLS 修复流水线职责不同：

- **下载引擎**负责对已抓取分段排序，先写入 fMP4 媒体所需的初始化数据，应用已配置的缺口策略，并保留播放列表不连续所形成的输出边界。
- **一致性修复**会在已交付分段出现不兼容的编解码器、分辨率、节目布局或 fMP4 初始化数据变化时开始写入新文件，并执行文件大小与时长限制。

该流水线不会改写 TS 或 fMP4 载荷内的时间戳，不能重建缺失媒体，也不会转码。被跳过的分段仍然是可观测的缺口；流水线会保持已交付输出的顺序，并在检测到需要新文件的格式变化时轮换输出。

## Streamlink 的 FFmpeg 可执行文件 {#streamlink-的-ffmpeg-可执行文件}

Streamlink 下载引擎的后端引擎配置 JSON 支持可选字段 `ffmpeg_path`。
`binary_path` 指定 Streamlink 本身；`ffmpeg_path` 指定负责重封装其输出的
独立 FFmpeg 进程：

```json
{
  "binary_path": "streamlink",
  "ffmpeg_path": "/opt/media-tools/ffmpeg",
  "quality": "best"
}
```

后端按顺序选择配置中的 `ffmpeg_path`、环境变量 `FFMPEG_PATH`，最后使用
`PATH` 中的 `ffmpeg`。省略该字段或设为 `null` 会保留环境变量和默认值的行为。
包含空格的路径会作为单个可执行文件路径传递，不需要 shell 引号，也不能附带参数。
选择在创建引擎实例时确定；修改环境变量后需要重启后端。显式路径不会继承任何
已注册 FFmpeg 引擎的设置；可执行文件不存在时录制启动失败，不会自动回退。
空字符串或仅包含空白的字符串仍视为显式可执行文件值，不会触发回退；
如需清除覆盖，请省略该字段或设为 `null`。

引擎编辑器提供 **FFmpeg 路径** 字段，修改其他设置时会保留该路径。清空字段或选择
**使用环境默认值** 会恢复环境变量及默认可执行文件的查找方式。请输入后端服务器上的
路径，不要添加 shell 引号；路径文本会原样保留。

在模板的 Streamlink 覆盖设置中，清空字段或选择 **使用引擎设置** 会移除覆盖并继承
引擎路径。选择 **使用环境默认值** 则写入显式 `null`，为该模板清除引擎路径，改用
`FFMPEG_PATH` 或 `ffmpeg`。

## 可执行文件检查 {#可执行文件检查}

FFmpeg 和 Streamlink 的版本检查限时三秒，必要时随后执行有时间上限的进程清理。引擎测试和自定义引擎解析会异步执行检查。无法启动或未在期限内完成版本探测的可执行文件会报告为不可用。同步启动初始化也会等待同样的有界检查。

不存在的命名引擎配置保留默认引擎回退行为。数据库访问失败、已保存配置损坏及无效覆盖会导致解析失败，不再静默改变实际使用的配置。

## 停止 Streamlink 录制 {#停止-streamlink-录制}

受支持的 Streamlink 8.5.0 读取器可停止获取新数据，同时把缓冲数据传给 FFmpeg 完成文件收尾。此过程必须在录制停止期限内完成，强制停止可能截断最后输出。

旧版、便携版、自定义可执行文件和不受支持的读取器保留正常录制行为，但停止时可能报告 `Streamlink cooperative drain incomplete`。详见[读取器支持范围及停止机制](../development/engines.md#停止-streamlink-录制)。

下载会话和媒体修复架构见 [Mesio 内部实现](./mesio.md)。
