# 常见问题

## 应该打开哪个地址？

使用本站下载的 Docker 文件时，打开 `http://localhost:15275`，API 位于 `http://localhost:12555/api`。使用示例 `.env` 的源码开发环境则使用前端 `15275` 和 API `8080`。参见[安装方式对照表](./installation.md#选择部署方式)。

## 初始账号是什么？

使用 `admin` / `admin123!`。登录后会被重定向修改密码，完成前其他受保护操作会被拒绝。仍使用默认密码的实例绝不能开放到网络。

## 为什么添加主播后没有立即生成文件？

只有频道正在直播、已启用监控、排程允许录制且有可用下载槽时，自动录制才会开始。请按[完成第一次录制](./first-recording.md)区分频道离线和安装失败。

## 应使用哪种频道 URL？

使用频道或直播间直接链接，不要使用个人主页、已录视频、搜索结果或平台首页。创建表单会根据 URL 识别平台。可在[支持的平台](../platforms/)查看可接受格式和 Cookie 要求。

## 是否需要 FFmpeg 或 Streamlink？

内置 Mesio 引擎不依赖这两个工具。标准 Docker 镜像包含该镜像支持的运行时工具。二进制或源码部署选择 FFmpeg 功能时应在 `PATH` 中提供 `ffmpeg`，选择 Streamlink 查找或下载行为时应提供 `streamlink`。参见[外部工具](./installation.md#外部工具)。

## 录制文件在哪里？

标准 Docker 配置把宿主机 `./output` 映射到容器 `/app/output`。路径本身取自数据库中的 `output_folder` 设置，全局、平台、模板和主播配置都可能覆盖它；`OUTPUT_DIR` 并不决定该路径。因此应以应用显示的解析后路径为准。参见[存储与容量](../operations/storage.md)。

## 清理磁盘后录制仍未恢复

打开**系统健康**并检查输出根组件：

- `storage_full`：释放足够空间并等待下次探测，通常无需重启。
- `not_found`：宿主机重命名或替换目录可能破坏了绑定挂载；确认挂载源后重启容器。
- `permission_denied`：修正宿主机路径的属主和权限。
- `read_only`：让文件系统恢复读写。
- `timed_out`：检查挂起的网络挂载或块设备。

只有磁盘写满会在录制进行中被发现：写入因空间不足失败时会立即报出 `storage_full`。其余几种是在录制启动时或由启动时的写入测试发现的，因此某个输出根在录制过程中变为只读或丢失权限时，会先表现为一次录制失败，直到下一次尝试才会出现在这里。

容器运行期间不要重命名或替换绑定挂载根目录。应删除现有目录内部文件、使用 `docker exec`，或先停止服务再变更挂载。参见 [Docker 绑定挂载排障](./docker.md#清理存储)。

## 原本可用的平台突然不能录制

平台可能随时变化。先确认频道确实直播，检查主播状态历史和日志，刷新所需凭据，并判断影响单个频道还是整个平台。提交已脱敏报告前先搜索 [GitHub Issues](https://github.com/hua0512/rust-srec/issues)。平台页注明支持时，可将 Streamlink 查找作为临时回退。

## 可以把 Rust-Srec 暴露到互联网吗？

必须先配置 HTTPS、安全 Cookie、网络限制、唯一密钥、备份、监控，并立即修改默认密码。先阅读[生产部署](../operations/production.md)和[安全](../operations/security.md)。不要仅因为示例 Compose 映射了宿主机端口就公开后端或 Swagger。

## 应如何升级？

固定相同前后端版本，阅读中间版本发布说明，进行一致备份；需要回滚时恢复该快照。参见[升级与回滚](../operations/upgrading.md)。

## 是否包含商业支持或 SLA？

项目没有公布商业 SLA、保证响应时间、LTS 分支或停止支持日历。社区渠道和应提供的诊断信息参见[支持与版本](../operations/support.md)。
