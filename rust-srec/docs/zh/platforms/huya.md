# 虎牙

[虎牙](https://www.huya.com) 是中国的游戏直播平台。

## URL 格式

```
https://www.huya.com/{房间号}
```

## 功能

- ✅ FLV 和 HLS 流
- ✅ 弹幕采集
- ✅ 多画质选项
- ✅ 自动 CDN 选择

::: info
- **认证说明**：通常**不需要**配置 Cookie。如有特殊需要，请在 **设置** → **平台** → **虎牙** 中把 Cookie 添加为账号凭据配置。
- **推荐格式**：虎牙支持 **FLV** 和 **HLS** 格式。建议优先使用 FLV 进行录制。
- **画质选择**：开启**强制原画质量**（`force_origin_quality`，默认关闭）可尝试获取最高画质。
- **API 模式**（`api_mode`）：`WEB`（默认）读取直播间页面；`MP` 和 `WUP` 使用虎牙的 App 接口，仅支持纯数字房间号。非纯数字房间号始终使用 `WEB`。
- **客户端类型 (ctype)**（`platform`）：随拉流请求发送的客户端标识，默认为 `huya_pc_exe`。
- **CDN 选择**：程序会自动尝试为您的网络环境选择最佳 CDN。
:::
