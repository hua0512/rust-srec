# 抖音

[抖音](https://www.douyin.com) 是中国的短视频和直播平台。

## URL 格式

```
https://live.douyin.com/{房间号}
```

## 功能

- ✅ FLV 和 HLS 流
- ✅ 弹幕采集
- ✅ 多画质选项
- ✅ 可选择 PC 或 移动端 API
- ✅ 互动玩法（互动直播）检测

## 认证

抖音通常无需账号即可正常录制：未提供 `ttwid` Cookie 时会自动获取。如需使用已登录的会话或自己的 `ttwid`，请在 **设置** → **平台** → **抖音** 的 **网络** 标签页中把这些 Cookie 添加为[账号凭据配置](../concepts/configuration.md#账号配置与选择)，并选中它。

::: warning
- **画质选择**：可在配置中开启 `force_origin_quality` 以强制获取最高画质。（实验性：如果所请求的画质不可用，可能导致无法获取视频流）。
- **地区限制**：部分直播有地区限制，可能需要中国大陆的代理（见[代理](../concepts/configuration.md#proxies)）。
- **不支持的内容**：目前不支持 **电台直播** (音频流) 的录制。
:::

::: info
- **流格式选择**：强烈建议优先录制 **FLV** 格式，以获得更好的稳定性。
- **双画面**：默认支持双画面数据采集。
- **互动玩法**：可配置自动跳过“互动玩法”（互动直播）的录制。
- **移动端 API**：如果 PC 端接口失效，可以尝试开启 `force_mobile_api`。
:::
