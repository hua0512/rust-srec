# Bilibili

[Bilibili](https://www.bilibili.com) 是中国的视频和直播平台。

## URL 格式

```
https://live.bilibili.com/{房间号}
```

## 功能

- ✅ FLV 和 HLS 流
- ✅ 弹幕采集
- ✅ 多画质选项
- ✅ 二维码登录支持

## 认证

哔哩哔哩账号是 Bilibili 平台上的[账号凭据配置](../concepts/configuration.md#账号配置与选择)。

### 二维码登录（推荐）

1. 进入 **设置** → **平台**，打开 **Bilibili**
2. 在 **网络** 标签页点击 **添加账号**，填写名称，保持选中 **扫码登录** 并点击 **显示二维码**（已有账号需要重新登录时，点击其所在行的 **重新登录**，或在 **…** 菜单中选择 **扫码登录**）
3. 使用哔哩哔哩手机 App 扫码
4. 登录完成后凭据配置即保存；要用它录制，点击账号列表上方的 **更改**，在 **账号选择** 中选中它并保存页面

### 手动设置 Cookie

在同一位置添加凭据配置，选择 **粘贴 Cookie**，并粘贴已登录浏览器会话的 Cookie：

| Cookie | 必需 | 说明 |
|--------|------|------|
| `SESSDATA` | 是 | 会话令牌 |
| `DedeUserID` | 可选 | 用户 ID；弹幕会以该账号身份连接 |

粘贴的 Cookie 不会自动续期：哔哩哔哩不再接受它们后，该账号需要重新登录。自动刷新需要扫码登录时随凭据配置保存的访问令牌和刷新令牌；浏览器中的 `ac_time_value` 不能用作此类令牌。

## 画质选项

在哔哩哔哩平台设置中设置**首选画质 (QN)**（`quality`），也可以在模板或主播中覆盖。它表示请求的最高画质；默认值 `30000` 会请求直播间提供的最佳画质。

| 画质 | 说明 |
|------|------|
| `30000` | 杜比视界（默认） |
| `20000` | 4K |
| `10000` | 原画 |
| `401` | 蓝光杜比 |
| `400` | 蓝光 |
| `250` | 超清 |
| `150` | 高清 |
| `80` | 流畅 |
| `0` | 可用的最低画质 |

## 批量检测

在哔哩哔哩平台的 **特定** 标签页中打开 **批量检测**，即可在一次请求中询问最多 100 个直播间是否在直播，而不是逐个检测未开播的直播间。该设置默认关闭，开播被发现的时间最多可能晚四分之一个检查间隔。参见[批量检测](./index.md#batch-detection)。

## 注意事项

::: warning
录制超清（1080P）及以上画质需要已登录的账号
:::

::: info
- 部分直播需要登录才能获取高画质
- 大会员专属直播需要对应会员资格
- 当主播刚开播时，HLS 流可能会有延迟。
:::
