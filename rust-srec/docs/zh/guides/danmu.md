# 弹幕录制与统计

## 启用弹幕录制

1. 查看[平台指南](../platforms/)，确认弹幕支持及登录要求。
2. 在全局设置中开启**录制弹幕**（`record_danmu`），或为平台、模板、主播单独覆盖。
3. 录制一场直播，在会话页面检查弹幕文件和统计。

视频和弹幕按录制分段关联。配对分段工作流会等待两个文件就绪后再处理。字幕转换和烧录的触发方式见[工作流触发器](../concepts/pipeline.md#管道触发器-pipeline-triggers)。

## 观看带弹幕的录像

在会话页面播放视频时，录制的弹幕会按视频时间显示在画面上。显示普通弹幕和醒目留言，不显示礼物。点击播放器控制栏中的气泡按钮可隐藏或显示弹幕；播放器较窄时，该开关会移到设置面板中的**显示弹幕**。屏幕排满时，多出的弹幕会被跳过，而不会互相重叠。

旁边的滑杆按钮会打开**弹幕设置**：

- **屏蔽类型**：滚动、顶部、底部、彩色弹幕或醒目留言。
- **不透明度**、**字号**和**速度**。
- **显示区域**：把弹幕限制在画面上方的 1/4、一半或 3/4，或使用全屏。区域越小越能避开字幕，也能减少密集弹幕。
- **合并重复弹幕**：10 秒内重复发送的相同内容只显示一次，并附带次数。
- **悬停时暂停弹幕**：鼠标指向的弹幕会停下以便阅读，并显示发送者。
- **在进度条上方显示弹幕热度**：显示弹幕最密集的位置。
- **屏蔽列表**：隐藏包含某个关键词的弹幕，或某个用户名的所有弹幕。关键词不区分大小写；用户名需完全一致。

这些设置和屏蔽列表保存在当前浏览器中，适用于所有录像。**恢复默认**会重置显示设置，但保留屏蔽列表。

只有保留弹幕 XML 文件时才会显示弹幕。如果工作流转换 XML 后删除了原文件，视频就不再带有弹幕。

## 配置统计摘要

在**弹幕统计**中选择排行长度、活动统计间隔、跟踪容量和额外停用词。这些设置遵循与录制相同的配置层级。默认值和范围见[字段参考](../reference/settings.md#弹幕统计)。

关闭统计仍会录制弹幕文件，但不再计算和保存包含观众名称的摘要。估计值使用 `≈` 标记；只有平台上报礼物时才显示礼物数据。

## 了解实时与中断会话

录制期间约每分钟保存一次统计。重启后继续已保存的计数，最近尚未保存的区间可能丢失。长会话会降低时间线精度，以保留整个录制时段。

视频继续录制时，弹幕会尝试重连。长时间断连会显示在系统健康页。平台从未交付的消息无法恢复。新 XML 文件过滤无效字符，已有文件不会自动修复。
