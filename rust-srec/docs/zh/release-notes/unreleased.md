## `unreleased`

## 管道与上传

- **本地文件删除后，仍可通过云端观看和下载录像**

  Rclone 预设新增**公开访问 URL** 设置，归档到云端后不再导致会话预览失效。对保持路径结构的存储（七牛、R2 等 S3 兼容桶、CDN、WebDAV/alist）选择 *URL 基础地址映射*：配置的基础 URL（支持与目标路径相同的主播/标题/日期占位符）会与每个已上传文件的相对路径拼接。对 Google Drive、OneDrive 这类网盘选择 *rclone link*：上传完成后逐文件获取分享链接（可选设置有效期）。两种方式得到的 URL 都会随上传记录保存；本地文件不存在后，会话页面的播放、预览和下载会直接使用云端副本，并给这类文件打上云端徽标。管道中途产生再上传的文件（例如转封装后的 MP4）现在也会出现在会话的录像列表中。基础 URL 配置错误会在任何传输开始前就判定任务失败；而分享链接获取失败不会影响任务成功，错误会记录在该文件的上传记录上并在界面显示。数据库现在保证每个会话文件只有一条录像记录，旧版本遗留的重复记录会在升级时自动清理。详见 [DAG 管道](../concepts/pipeline.md#rclone-公开访问-url-rclone)。

- **支持把录像上传到百度网盘**

  新增 `baidupcs` 管道处理器，通过 BaiduPCS-Go 命令行工具把录像上传到百度网盘，Docker 镜像已内置该工具。像其他上传步骤一样加进管道即可：目标文件夹支持主播、标题、日期等占位符，同名文件可以跳过或覆盖，上传的实时进度、逐文件记录和主播卡片上的上传状态与 rclone 完全一致。登录直接在预设编辑器里完成——粘贴一次网盘 Cookie（或 BDUSS 和 STOKEN），账号卡片就会显示当前账号和剩余空间。勾选**记住凭据以便自动重新登录**后，登录会话过期时上传任务会自行重新登录，半夜录完的直播照样能上传进网盘；不勾选则凭据只交给 BaiduPCS-Go，应用本身不保存。如果记住的凭据本身失效了，会收到一条提醒通知，后续尝试也会暂停一小时，不会反复请求百度。退出登录会一并清除记住的凭据。由于 BaiduPCS-Go 的退出码无法反映上传结果，rust-srec 会解析它的逐文件输出来判定成败，重试任务时只重传没有成功的文件。详见 [DAG 管道](../concepts/pipeline.md#百度网盘-baidupcs)。

## 弹幕

- **录制过程中即可查看弹幕统计**

  弹幕统计不再等到直播结束才出现：录制进行时，大约每分钟保存一次统计快照，会话页面的弹幕面板（总数、活跃度时间线、活跃用户、高频词）在直播还在进行时就会逐步填充。如果录制中途程序崩溃或主机重启，最多只丢失最后一分钟的统计，而不是整场。

- **超长直播的活跃度时间线覆盖全场**

  弹幕活跃度图表过去只保留最近六小时的完整数据，更长的直播会悄悄丢掉最早的数据点。现在达到上限时会把图表分辨率减半，因此 12 小时的录制也能从第一分钟画到最后一分钟，只是粒度更粗。

- **活跃用户榜可展开**

  会话页面的活跃用户卡片默认显示最活跃的 6 位，现在可以展开查看完整排名（每场最多记录 32 位）。

- **中文高频词切分更准确**

  高频词统计现在会把全角标点（`，` `。` `！` `？` 等）、符号和表情当作分隔符。此前只按空格和半角标点切分，没有空格的中文弹幕会被整句当成一个"词"。

- **新增互动人数指标**

  会话弹幕面板现在会显示本场有多少不同用户发过言（内存有界的估算值，误差约 1–2%），与弹幕总数并列展示。此版本之前录制的场次显示为 "—"。

- **新增礼物排行**

  对于在弹幕流中上报礼物的平台（Bilibili、斗鱼、Bigo、SOOP 等），会话页面新增两张图表：送礼排行与热门礼物，均按礼物件数而非消息条数统计。只有当场收到过礼物时才会显示。

- **移除 `danmu_sampling_config` 配置项**

  这个模板/主播配置项从未产生过任何效果——统计一直是逐条计数的。该字段已从 REST API（`/api/templates`）和数据库中移除；现有配置会自动清理，包含该字段的旧导出文件仍可正常导入。
