# 更新日志

## `unreleased`

## 新增功能

- **会话页面**：观看录像时，录制的弹幕会按视频时间显示在画面上。播放器中的**弹幕设置**面板可以屏蔽弹幕类型，调整不透明度、字号、速度和显示区域，合并重复弹幕，悬停时暂停弹幕，在进度条上方显示弹幕热度，并屏蔽关键词或用户。设置会被记住，大型弹幕文件加载时页面不会卡顿。参见[弹幕录制](../guides/danmu.md#观看带弹幕的录像)。
- **播放器页面**：播放直播时，弹幕会实时显示在画面上，同样可以用弹幕按钮和**弹幕设置**控制。网格中的每个播放器显示各自直播的弹幕，隐藏弹幕时不会接收弹幕。参见[观看带弹幕的直播](../guides/danmu.md#观看带弹幕的直播)。
- **Twitch**：新增平台设置 **允许 H.265 (HEVC)** 和 **允许 AV1**，可录制部分频道仅以这些编码提供的更高画质。两项默认关闭，未开启时录制仍为 H.264。详见 [Twitch](https://docs.srec.rs/zh/platforms/twitch)。

## 修复

- **预设**：打开使用 NVIDIA（NVENC）编码的已保存重封装预设或工作流步骤时，编码预设可能被改为 Medium，下次保存时会保留这一更改。现在会保留已保存的预设。
- **预设**：预设编辑器中各处理器的名称和图标现在与工作流编辑器和任务页面保持一致。
- **预设**：撤销对已保存预设的修改后，**保存更改**按钮现在会重新隐藏。此前大多数处理器的预设仍会显示该按钮，就像还有未保存的修改。
- **通知**：Webhook 渠道的超时时间现在最多为 300 秒，与 Gotify 渠道一致。服务器等待的时间从不超过这个值，更大的设置并不会生效。
- **预设**：重封装设置的空白输入框和预设 ID 输入框中显示的示例值现在已翻译。
- **工作流**：在预设步骤中使用**分离并编辑**时，现在总是以预设保存的设置为准。此前在步骤中显示的预设设置看似只读，但通过键盘做出的修改会在分离时被悄悄复制到步骤中。
- **主播页面**：某个主播保存的设置无法读取，或含有录制器可以接受的值时，不会再导致整个主播列表无法加载。这类值包括：大小写不同或录制器无法识别的提取器名称、为 0 的离线确认次数或不足一秒的确认间隔、只设置了部分数值的重试策略、未保存格式列表的流选择，以及重试或超时为空的工作流步骤，例如来自导入的配置。录制器可以接受的值会按其实际采用的方式显示；无法读取的设置会显示为未配置。
- **平台、模板和全局设置**：大小写不同或录制器无法识别的提取器名称，不会再导致平台列表、模板列表或全局设置页面无法加载。平台和模板中只设置了部分数值的下载重试策略、未保存格式列表的流选择，以及重试或超时为空的工作流步骤，不会再显示为未配置，也不会在下次保存时被删除。未设置的重试数值会显示录制器使用的默认值。
- **平台和模板**：**地址获取方式** 设置现在会显示已保存的选项，保存页面上的其他更改时，也不会再把 **始终使用 Streamlink** 重置为默认值。
- **安全**：其他网站构造的链接可能让流代理显示一个以已登录用户身份操作的页面。现在流代理只转发视频、音频、图片和播放列表，并拒绝来自其他网站的请求。
- **安全**：登录失败时不会再把输入的密码写入服务器日志，退出登录失败时也不会再写入登录令牌。
- **安全**：同一地址下其他端口或子域名的页面可能让网页界面以已登录用户的身份执行操作。现在网页界面会拒绝这类请求。如果网页界面位于会改写浏览器访问地址的反向代理之后，并且所有操作都提示 "Request refused"，请让代理转发原始地址，或将该地址加入 `CSRF_TRUSTED_ORIGINS`（参见[环境变量](https://docs.srec.rs/zh/reference/environment)）。
- **安全**：向网页界面发送 `..` 这类 ID 时，可能让它执行与请求不同的服务器操作。现在会拒绝这类 ID。
- **安全**：直接从服务器打开的录制文件（例如弹幕 XML 文件）不会再以网页界面的身份运行脚本。
- **安全**：使用平台账号播放直播时，平台返回的更多类型的错误页面和账号数据现在会被拒绝，不再转交给播放器。
- **Docker**：网页容器的访问日志不再记录播放、下载和实时更新链接中附带的登录令牌。
- **网页界面**：服务器未响应的请求现在会在 15 秒后报错（平台检测、连接测试和备份等较慢的操作会等待更久），页面不再一直等待。关闭或刷新标签页时，也会停止服务器仍在为该页面处理的请求。
- **登录**：登录失败时现在会显示服务器给出的原因，而不是内部服务器地址。
- **会话页面**：现在可以通过页码翻到所有会话。此前页数按每页 50 个会话计算，而每页实际只显示 20 个，超出最后一个页码的会话无法从列表中找到。
- **会话页面**：列表加载失败时会提示失败并提供**重试**，不再显示为没有任何录像。搜索或筛选没有匹配结果时，会提示没有符合条件的会话并提供**清除筛选**。
- **仪表盘**和 **API 密钥**设置：某个区域加载失败时会显示错误和**重试**按钮，不再一直加载或显示为空。
- **列表**：主播、媒体产物、处理任务、预设、工作流、模板、平台或通知事件列表加载失败时，页面会保留标题栏和搜索框，并显示错误和**重试**按钮。无法打开的流水线、模板、平台、引擎、预设或工作流现在会提供返回所在列表的链接。
- **列表**：会话列表现在通过页面标题栏中的**选择**按钮开启多选，并使用与其他列表相同的选择栏。各页面的空列表样式保持一致，主播卡片显示各平台自己的图标和颜色，全局设置和主题设置只在页面足够宽时才并排显示各区块。
- **列表**：在会话、媒体产物、处理任务、预设或工作流列表中删除最后一页的最后几项后，会回到上一页，不再停留在显示“未找到”的空白页。
- **列表**：媒体产物、处理任务、预设和工作流列表地址中的页码现在与其他列表一样从 1 开始计数，各处的 `?page=2` 都表示第二页。之前保存的这些列表的链接，打开的会是原来的前一页。
- **确认操作**：删除主播或会话时改用应用内对话框确认，不再弹出浏览器提示框；删除主播的过滤器前也会先确认，不再直接删除。
- **未保存的更改**：在模板、平台、引擎、预设或工作流编辑器中有未保存的修改时离开，会先询问是否放弃。全局设置和主播编辑器原本就会询问，现在改用应用内对话框。
- **实时更新**：登录状态续期时，下载、上传和检测进度不会再中断一段时间，放在后台的标签页也是如此。
- **浏览器通知**：应用的标签页在后台时，严重事件的通知现在也会及时弹出，而不是等回到该标签页后才出现。
- **浏览器通知**：账号登录失效或需要重新登录的通知现在会注明平台并说明原因，而不是只显示“紧急”。
- **浏览器通知**：输出文件夹无法写入的通知现在会注明是哪个文件夹，处理队列已满的通知会说明有多少任务在排队，而不是只显示“紧急”。
- **通知**：处理队列严重积压的通知现在会显示队列已达到 500 个任务，即发送该通知的实际阈值。之前显示的是 200。
- **主播卡片**：应用的实时连接跟不上时结束的录制，不会再一直显示为录制中；与服务器的连接恢复后，检测历史和主播状态会立即更新，不会再过期好几分钟。
- **会话页面**：仍在录制的会话无需刷新页面，每个分段完成后就会显示出来，时长和大小保持更新，结束时也会显示结束时间。
- **任务页面**：运行中的任务页面会实时显示进度，向服务器请求更新的次数也大幅减少。
- **任务页面**：日志很长的任务在运行或滚动时不再让页面卡顿，只绘制屏幕附近的日志行。因此浏览器的查找只能搜到这些行，日志新增了**复制日志**按钮，可复制所有已加载的日志行；浏览器不允许复制时会改为下载文件。
- **任务页面**：删除任务时会在应用内弹窗确认，然后打开任务列表。此前会返回上一个页面，从链接打开任务时会离开应用。
- **任务页面**：输入和输出大小会以合适的单位（KB、MB、GB）显示，不再总是以 MB 显示，标签也已翻译。
- **FLV 录制**：使用 Mesio 引擎录制的文件现在会将创建者记录为 Mesio（此前为过时的版本号），并记录实际的数据大小（此前为 0），媒体工具显示的文件信息因此准确。
- **FLV 录制**：使用 Mesio 引擎并开启 **修复 FLV 流** 时，直播中途重新推流（例如主播开启了直播延迟）后，录制可能变成一个超长文件，播放器显示时长为 0 秒，也不会按时长限制分段。现在录制在这类重新推流后会继续正常计时，并按设置分段。
- **FLV 录制**：使用 Mesio 引擎并开启 **修复 FLV 流** 时，若直播流未提供文件信息，浏览器播放器现在也能显示录制文件的时长并拖动进度。
- **FLV 录制**：使用 Mesio 引擎并开启 **修复 FLV 流** 时，直播流在画面开始前发送多组相互冲突的设置，录制文件现在也可以正常复制和转换。此前复制或转换这类文件时，可能沿用较早的设置，而不是直播流最终采用的设置。
- **FLV 录制**：使用 Mesio 引擎并开启 **修复 FLV 流** 时，若直播的计时从略早于零的位置开始，录制可能被压缩成几秒钟，或音画不同步达数秒。现在这类录制会从头正常播放，音画保持同步。
- **FLV 录制**：使用 Mesio 引擎时，录制文件现在会记录精确的时长，不再向下取整到整秒，播放器因此能显示正确的时长，进度条末尾也与录制结尾一致。会话页面的 **录制内容** 标签页也会显示精确的时长。
- **Huya**：普通弹幕现在不再记录颜色，转换的字幕和烧录的视频中会显示为白色，而不是蓝色。平台本身带颜色的弹幕仍保留原颜色。更新前录制的弹幕文件仍为蓝色。
- **Twitch**：刚开播或刚下播、暂时无法播放的频道现在会显示为未开播，不再导致开播检测报错。Twitch 拒绝播放时，会显示 Twitch 返回的错误信息。
- **Twitch**：不存在的频道现在会显示为未找到，被封禁的频道显示为已封禁，不再在每次开播检测时报数据错误。

- **Twitcasting**：平台设置中的 **直播密码** 现在可以解锁带密码的直播。此前只有加在主播 URL 中的密码（`?password=...`）有效；URL 中的密码仍然优先。
- **YouTube**：指向已上传或已结束视频的链接现在会显示为未开播，而不是正在直播，不会再在每次开播检测时被重复录制。正在进行的直播不受影响。
- **读屏软件**：搜索框、筛选菜单、开关、滑块，以及只显示图标的按钮（例如圆形添加按钮和**清除筛选**）现在都有读屏软件可以读出的名称。会话、处理任务和通知事件页面的筛选按钮现在会说明是否已选中；此前读出时缺少名称的设置（例如 Huya 和 TikTok 的 API 模式）现在会读出名称。
- **键盘和触屏**：此前只在鼠标悬停时出现的按钮（例如通知事件中的**查看详情**、工作流中的步骤按钮和**日志**设置中的移除按钮）现在在触屏上以及用键盘切换到时也会显示。**浏览器通知**或**桌面通知**卡片、模板中的平台设置区块、会话预览上的播放按钮以及会话的多选现在都可以用键盘操作。
- **中文界面**：登录、修改密码、主播、工作流、通知渠道、模板和预设等表单的错误提示现在显示为中文，不再是英文。日期选择器显示中文的月份和星期，会话页面的数字和 API 密钥的日期按应用语言而不是浏览器语言显示；启动画面、部分卡片标签、编码预设说明和读屏标签也已翻译。
- **会话页面**：页面变窄时（例如打开侧边栏后），**弹幕统计**的数据块会换行排列，不再挤在一行。
- **备份与恢复**：导入配置后，通知渠道及其订阅、预设、工作流、代理，以及已打开的主播、模板或引擎页面，无需刷新页面就会显示导入的设置。
- **复制按钮**：浏览器拒绝复制时（例如通过局域网内的普通 HTTP 地址打开应用），复制文件路径、API 密钥、MCP 配置或通知事件时会提示复制失败，不再显示复制成功或毫无反应。
- **健康状态**：尚未检测的组件现在在仪表盘、健康页面和存储用量条中都显示为灰色，不再在仪表盘上显示为红色、在存储用量条上显示为绿色。
- **会话页面**：已结束的会话不再在主播头像上显示绿色的直播圆点；仍在录制的会话，时长会持续增加，不再停留在打开页面时的时长。
- **工作流**：在步骤库中使用输入法（例如拼音）输入搜索内容时，不会再用尚未完成的输入进行搜索。
- **日志与主播页面**：日志文件列表或主播的状态检查历史加载失败时，页面现在会显示错误并提供**重试**按钮，不再只显示一片空白。
- **主播页面**：在主播列表中启用、停用或批量修改主播后不久打开其页面，现在会显示修改后的设置；与服务器的连接恢复后，已打开的主播页面也会更新。
- **工作流**：步骤库现在会列出刚刚创建或修改的工作流，不再显示之前的列表。
- **会话页面**：弹幕列表中的消息时间现在按应用语言而不是浏览器语言显示。
- **备份与恢复**：选择导入的文件大小现在以合适的单位（KB、MB）显示，不再总是以 KB 显示。
- **录制**：中文、日文等多字节文字的较长直播标题不再使文件名超出磁盘限制而导致录制无法保存。现在文件名和文件夹名中的标题会被缩短，名称的其余部分（例如日期和时间）保持不变。
- **任务页面**：已完成的任务现在会显示输入和输出大小。此前这两项一直为空。
- **浏览器通知**：通知无法送达时，服务器日志现在只记录推送服务的地址，不再记录能识别你浏览器的完整订阅地址。
- **元数据**和**重封装**步骤：开启**处理成功后删除源文件**但删除失败时，任务日志中的警告现在只显示一次，而不是两次。
- **桌面应用**：保存**桌面通知**设置时不再短暂删除设置文件，因此设置不会在保存过程中被重置为默认值。
- **备份与恢复**：备份现在会保留每个平台和模板的 **地址获取方式** 选项（例如 **始终使用 Streamlink**）。此前在新安装中恢复备份时，这些选项都会被重置为默认值，重新改为自动获取地址。
- **Streamlink 录制**：**最大分片大小** 设置现在对使用 Streamlink 引擎的录制生效。此前 Streamlink 录制会超过该限制继续写入同一个文件；现在达到限制时会结束当前分片并在新文件中继续录制，与 FFmpeg 引擎一致。使用 Streamlink 录制的 MP4 文件在浏览器和播放器中也能更快开始播放，与 FFmpeg 引擎录制的文件相同。
