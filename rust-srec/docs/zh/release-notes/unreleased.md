## 升级前须知

- **移除事件钩子**

  平台、模板、模板里的平台覆盖以及主播页面上的**钩子**标签页都已移除，里面保存的六条 shell 命令也一并删除。这些命令只是存下来并按配置层级合并，从来没有真正执行过，所以不会有任何正在用的功能因此失效。升级时数据库里已保存的命令会被清除，导出的备份中也不再包含，需要留底请在升级前自行复制。想在这些时刻触发外部动作，请到**通知**里订阅一个通知渠道，Webhook、Telegram、Gotify、Discord 和邮件都可以，详见[通知系统](../concepts/notifications.md)。

## 主播与平台

- **Bigo 主播一开播就能录上**

  Bigo 检测原本共用同一个访问令牌，而这种令牌只能用一次，从第二次检测起响应里就不带直播地址，于是被当成了没开播。现在每次检测各取一个令牌；没有直播地址时也会记成一次失败的检测，不再当作离线。
