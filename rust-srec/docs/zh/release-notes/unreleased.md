# 更新日志

## `unreleased`

## 工作流与文件处理

- 修复了 rclone 上传的尝试次数超过预设“最大重试次数”的问题。此前 rclone 会在每次失败后自行重试最多 3 次，然后才进入下一次重试，因此失败的上传实际可能执行配置次数的三倍，而任务进度中看不到这些尝试。现在任务进度中显示的每次尝试都只上传一次，总次数由“最大重试次数”限制。如需恢复 rclone 自身的重试，可在预设的额外参数中传入 `--retries`。
- 修复了可以删除或重命名仍被流水线使用的任务预设或工作流的问题。全局设置、平台、模板、主播以及其他工作流中的流水线按名称引用预设和工作流，删除或重命名后这些流水线在运行时会失败。现在此类操作会被拒绝，并提示其仍在何处被使用；以 replace 模式导入配置时，导入后的流水线仍在使用的预设和工作流会被保留，并以警告列出。

## Web 界面

- 修复了网页界面在本应自行说明问题时直接显示服务器原始消息的问题。受影响的情况包括：代理名称已被占用、代理已在别处被修改、站点已有账号配置，以及仍在使用某个代理或账号配置的设置列表。此外，取消一个刚刚结束的任务会报错，需要修改密码的会话也要等到下次加载页面时才会跳转到修改密码页面。桌面应用不受影响。
