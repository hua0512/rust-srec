# 更新日志

## `unreleased`

## 录制与恢复

- 修复了 Bigo 账号被风控后，正在直播的主播仍显示为未开播的问题。被风控的账号仍显示为已登录，但 Bigo 会告诉它所有直播间都未开播，因此不会录制，rust-srec 也不会换用其他账号或改为未登录检测。现在 rust-srec 会查看一个 Bigo 列为正在直播的直播间来发现这种情况，并将该账号暂停使用 30 分钟。在此期间，检测改用账号池中的其他账号；若开启了 **没有可用账号时以未登录状态检测**，则以未登录状态继续检测。参见 [Bigo Live](https://docs.srec.rs/zh/platforms/bigo)。
- 修复了未配置账号的 Bigo 主播在 Bigo 要求登录时会暂停检测长达一小时的问题。Bigo 往往在几次检测之后就不再要求登录，但此前每次要求都计为一次错误，主播很快会进入越来越长的暂停，错过直播，只能禁用再启用。现在这类检测会显示 **账号需要登录**，并按原来的间隔继续检测。

## 工作流与文件处理

- 修复了 rclone 上传的尝试次数超过预设“最大重试次数”的问题。此前 rclone 会在每次失败后自行重试最多 3 次，然后才进入下一次重试，因此失败的上传实际可能执行配置次数的三倍，而任务进度中看不到这些尝试。现在任务进度中显示的每次尝试都只上传一次，总次数由“最大重试次数”限制。如需恢复 rclone 自身的重试，可在预设的额外参数中传入 `--retries`。
- 修复了可以删除或重命名仍被流水线使用的任务预设或工作流的问题。全局设置、平台、模板、主播以及其他工作流中的流水线按名称引用预设和工作流，删除或重命名后这些流水线在运行时会失败。现在此类操作会被拒绝，并以对话框列出其仍在何处被使用，每项均可点击跳转；以 replace 模式导入配置时，导入后的流水线仍在使用的预设和工作流会被保留，并以警告列出。

## Web 界面

- 模板卡片现在会在 **使用情况** 中显示使用该模板的主播数量，并可跳转到这些主播。删除仍被主播使用的模板时，现在会说明无法删除的原因并提供 **查看主播** 按钮，而不再显示原始的服务器错误。
- 修复了网页界面无法识别部分服务器响应、转而显示笼统错误或服务器原始消息的问题。没有弹幕统计的场次会显示加载失败和 **重试** 按钮，而不是说明暂无弹幕统计；在播放器中刷新已过期的直播流会直接失败，而不是重新获取直播流。代理名称已被占用、已有相同地址和用户名的代理、代理已在别处被修改、站点已有账号配置等情况会显示服务器原始消息，而不是相应的说明或仍在使用它们的设置列表。此外，取消一个刚刚结束的流水线会报错，需要修改密码的会话要等到下次加载页面时才会跳转到修改密码页面，无法连接服务器时的登录错误也没有翻译。桌面应用不受影响。
- 修复了在主播编辑页保存、点击返回箭头或取消 **添加主播** 后，主播列表总是回到第一页的问题。现在列表会回到离开时的页码，并保留原有的搜索、筛选和排序。
- 修复了主播、流水线任务、任务预设等列表在所有项目都能在一页显示时，**每页**选择器随之消失的问题。选择更大的每页数量后便无法再改回较小的值。现在只要较小的每页数量会让列表重新分页，选择器就会保持显示。
- 主播列表默认排序时，同一状态内的主播现在按最近一次开播时间从近到远排列，而不再按优先级排列。正在直播的主播仍排在最前，出错的主播紧随其后，接着是未开播的主播，现在排在已禁用的主播之前。刚刚下播的主播不会再排到已禁用或几个月未开播的主播后面。仪表盘上的直播中主播现在也按开播时间排列。按 **状态** 排序时现在也使用同样的顺序，而不再按字母顺序排列（那样会把直播中的主播排到列表中间）。按名称排序现在不再区分大小写。
