# 更新日志

## `unreleased`

本次更新新增 API 密钥与 MCP 接入、百度网盘上传、工作流步骤重试和可配置的弹幕统计，并修复录制关闭、重启恢复、文件处理及日志泄露凭据等问题。

## 升级前须知

- **登录会话：** 现有访问令牌需要通过有效的刷新令牌更新，或重新登录。退出登录、修改密码和成功导入配置会撤销相应登录会话。API 客户端必须串行刷新令牌；重用已消费的刷新令牌可能撤销该用户的全部会话。详见[会话安全](../operations/security.md)。
- **已泄露的凭据：** 新日志会隐藏 Cookie、令牌和密码，但不会改写旧日志。如果曾分享包含凭据的日志，请更换相关凭据。
- **过滤器时区：** 新过滤器默认使用 UTC。迁移和旧版备份导入会保留现有 TimeBased 本地时间安排。编辑器现支持选择 UTC、服务器本地或 IANA 时区。详见[时区兼容性](../operations/upgrading.md#过滤器时区兼容性)。
- **数据库迁移：** 预设和模板时间戳统一为 Unix 毫秒，并新增索引以加快工作流和媒体产物列表查询。无效的历史时间戳会使迁移停止，原数据不变；请按[修复说明](../operations/upgrading.md#预设和模板时间戳)处理。创建索引时会扫描相关表。
- **Execute 模板：** 不受支持的占位符用法会在启动前报错。不适合 Shell 模板的任务可改用新增的 `program`/`args` 模式或固定脚本。Windows 的程序模式不支持批处理文件。详见[支持的语法](../reference/processors.md#execute-execute)。
- **源码构建：** 前端和文档现需要 Node.js 26。Docker 和预编译安装不受影响。
- **移除的设置：** `danmu_sampling_config` 已从 API 和数据库移除，该设置从未影响统计；旧版导出仍可导入。已保存的 `EmailConfig.batch_window_secs` 仍被忽略，该字段已从 Rust 接口移除。
- **Rust 集成：** 移除了部分未使用的后端、调度器、下载器和指标接口。请使用统一的 `domain::StreamerState` 和受支持的子系统快照。详见[后端接口变更](../development/architecture.md#后端-rust-接口)、[调度器变更](../development/architecture.md#调度器状态与退避)和[下载器变更](../development/architecture.md#下载器-rust-接口)。

## 新增功能

- **API 密钥与 MCP：** 新增可设置有效期的 API 密钥，支持 `read_only` 和 `full` 权限；内置 MCP 服务位于 `/api/mcp`，可查询录制、分析弹幕和管理配置。**设置 → API 密钥**支持创建、撤销密钥和生成 MCP 客户端配置。密钥仅显示一次，以哈希形式存储；只读密钥不能获取凭据或配置。详见 [API 密钥与 MCP](../api/api-keys-mcp.md)。
- **百度网盘上传：** 新增 `baidupcs` 处理器，Docker 镜像内置 BaiduPCS-Go。预设编辑器支持登录、查看配额和可选的自动重新登录。上传支持目标路径模板、跳过或覆盖策略、逐文件结果和未确认文件重试。记住的凭据保存在服务端，退出登录时删除。详见[百度网盘](../reference/processors.md#百度网盘-baidupcs)。
- **工作流重试与超时：** 可在编辑器或步骤定义中设置 `retry.max_attempts`、`retry.backoff_secs` 和 `timeout_secs`。计划重试在重启后保留，依赖步骤继续等待；取消工作流会取消待执行的重试。详见[按步骤设置](../reference/workflows.md#按步骤设置重试与超时)。
- **直接执行程序：** 在 Shell 命令模式之外新增 `program` 和 `args`。参数中的空格、引号、空值和替换数据保留字面含义。两个工作流编辑器均支持新模式，切换模式时保留输出扫描设置。
- **Streamlink 的 FFmpeg 选择：** 引擎设置和模板覆盖新增 `ffmpeg_path`。可指定可执行文件、继承引擎设置，或使用 `FFMPEG_PATH`/`ffmpeg`。含空格的路径原样保留。详见[引擎配置](../concepts/engines.md#streamlink-的-ffmpeg-可执行文件)。
- **管道批量操作：** **管道任务**新增多选及批量取消、重试和删除操作。操作失败的项目保持选中，便于再次尝试。
- **媒体删除：** **媒体产物**支持单项和批量删除。默认只删除记录；勾选**同时从磁盘删除文件**才会删除录制文件，会话大小随之更新。
- **存储空间显示：** 系统健康页显示各录制磁盘的剩余空间和使用量，包括覆盖配置指定的磁盘。仪表盘显示使用率最高磁盘的剩余空间。

## 录制与恢复

- 修复关闭顺序，使录制工具能在退出前完成文件写入、保存最后分段并关闭弹幕文件。子进程随应用停止，包括 macOS 上父进程已开始退出的情况。
- 独立后端新增默认 30 秒的关闭期限。可通过 `RUST_SREC_SHUTDOWN_TIMEOUT_SECS` 调整，并将 Docker 的停止宽限期设得更长。强制或未完成的关闭会在下次启动时提示，只有确认恢复完成后才清除恢复警告。详见[关闭设置](../reference/environment.md#关闭)。
- 为受支持的 Streamlink 8.5.0 读取器新增协作停止，使已缓冲数据能在收尾前传给 FFmpeg。不受支持的读取器和强制停止会报告数据排空未完成。详见[支持范围与限制](../concepts/engines.md#停止-streamlink-录制)。
- 修复 FFmpeg 和 Streamlink 的最后分段上报：仅在确认进程清理完成后标记分段完成，新分段重新计算字节统计。在首个 HLS 分段到达前停止 Mesio 不再报告引擎故障。
- 修复重启后的未结束会话：仍在直播时复用原会话，确认下播后结束会话并恢复最终后处理。
- 修复重复结束会话、覆盖结束时间及旧事件停止新会话的问题。关闭应用和禁用主播不再上报错误的下播状态。
- 修复分段数据库写入失败导致整场录制停止的问题。现在报告保存失败，并继续录制。
- 修复输出错误分类，即使同时断流或 FFmpeg 正常退出，也会保留存储错误。磁盘写满会触发存储告警和重试限流，不再让各主播反复失败。
- 修复删除主播时丢失录制历史的问题。删除会等待全部录制和后处理完成，并在重启后继续。清理完成前主播 URL 仍被占用，需要重新创建同一 URL 的脚本应稍后重试。
- 修复配置导入打断直播录制或重复发送开播通知的问题。新主播立即开始监控，被拒绝的导入不影响运行中的任务。替换导入会暂时保留录制收尾所需的模板和预设，并给出警告。
- 修复可恢复的内部错误导致监控停止，以及快速禁用、启用导致监控重复或缺失的问题。连续崩溃十次后停止自动恢复；主播已移除等终止状态不会触发重启。详见[重启上限](../operations/monitoring.md#调度器重启上限)。
- 修复调度器繁忙时丢失开始、结束反馈，以及旧更新覆盖当前录制状态的问题。离线检测使用解析后的全局、平台、模板和主播设置；周期检查加入 ±10% 时间偏移以分散负载。错误计数较大时，退避仍不超过一小时。
- 修复单个主播的登录凭据在编辑或批量操作后丢失的问题。共用的平台凭据按顺序刷新，等待中的录制使用更新后的 Cookie。
- 修复 Windows 上 FFmpeg 分段录制的 Unicode 路径。标题、名称和具体目录中的百分号保持原文，配置的日期占位符仍正常展开。
- 引擎测试改用有时限的异步版本检查，无效设置会报错，不再静默套用默认值。Mesio 诊断显示所链接库的版本；自定义静默日志选项不会禁用 FFmpeg 进度跟踪。

## 工作流与文件处理

- 保存工作流时新增校验，检查缺失预设、未知处理器、依赖环，以及删除或移动文件时仍有其他步骤读取同一文件的情况。通过选项删除源文件的步骤会给出警告。详见[工作流校验](../concepts/pipeline.md#自动清理)。
- 修复工作流失败处理，仅取消失败步骤的依赖步骤。独立分支可继续完成，重试只重新运行失败或已取消的步骤。属于工作流的任务会提示重试整个工作流。
- 修复重试后工作流卡住、成功结果未交付及部分文件处理失败仍被标记成功的问题。错误会列出失败文件，保留已生成文件；重试历史保留日志、耗时、大小和先前输出。
- 修复重启恢复，继续未完成的处理且不重复执行已完成步骤。应执行但尚未创建的处理也会补上；不会对本次更新前已完成的录制追溯执行新处理。
- 修复取消和删除操作，使运行中的任务停止，工作流标记为已取消，包括 `DELETE /api/pipeline/{pipeline_id}`。已取消工作流仍可重试，已撤回任务不会自行重启。
- 修复关闭流程，处理完已接收的管道事件，并在关闭期限前停止耗时任务。短任务可完成，中断的任务在重启后重新执行。已结束会话的延迟清理不再阻塞关闭。
- 调整队列顺序：同一优先级先处理进行中工作流的后续步骤，再处理新工作流；各组内按入队先后执行。较高优先级仍优先。降低 CPU/I/O 并发上限会立即限制新任务，已运行任务可继续完成。
- 超时诊断新增配置期限、步骤、处理器、当前文件和最近传输进度。重启后重新排队的任务会清除旧进度。任务日志保留重复消息，不重复写入已保存记录。
- 修复未知处理器导致会话一直显示处理中的问题。ZIP 预设现在可正确执行，使用不可用处理器的历史任务会在启动时失败。工作流创建失败会释放临时跟踪数据，无效的已保存预设 JSON 会在创建任务前被拒绝。
- 修复工作流输出顺序，使其遵循工作流定义。无输入文件的步骤直接完成，`execute` 仍执行命令。恢复时按已保存的视频路径匹配弹幕，无法唯一匹配时给出警告。
- 将生成的 `_inputs.json` 附加文件改为管道内部保存的配对数据。旧附加文件已不再使用，可删除。字幕只与自己的录制分段配对，文件移动后仍有效；Execute 脚本可读取 `{manifest_json}`。
- 修复媒体处理器的输出提交：先写临时文件，拒绝输入与输出路径冲突，批次失败时回滚。处理失败或取消会保留源文件和已有目标文件；关闭覆盖选项也能防止并发写入覆盖文件。详见[处理器行为](../development/pipeline.md#处理器结果约定)。
- 修复输入、输出指向同一文件时，删除源文件操作误删新转换文件的问题。字幕过滤器现支持路径中的单引号和过滤器分隔符。
- 修复命令或音频探测取消、超时后残留子进程的问题。清理包含后代进程，输出收集有大小限制。
- 修复复制、移动和归档接受重复目标名称的问题。移动任务首次执行会拒绝缺失输入；重试可识别先前已移动的文件。部分 rclone 和百度上传失败时保留各文件的实际结果。
- 修复百度上传反复重试永久拒绝的文件，以及文件列表过长时失败的问题。Rclone 支持上传来自不同目录的输入；上传日志省略账号信息和含凭据的连接参数。
- 新增 ZIP64 支持，可归档大于 4 GiB 的录制文件。重名 ZIP 条目会在写入前被拒绝，可启用 `preserve_paths` 或重命名输入。
- 修复录制时长短于缩略图时间点时的处理，改为使用首帧；没有可用帧的录制直接传递给下一步。无重编码的音频提取使用与编码匹配的扩展名。
- 修复关闭透传时字幕烧录丢弃未处理视频的问题。批量任务报告汇总文件大小，FFmpeg 进度时间戳统一使用毫秒。
- 修复 Execute 输出扫描，支持目录占位符，且仅接收命令启动后新建并修改的文件。无法读取的扫描目录会使步骤失败。工作流中的 Execute 步骤不接收 `{output}` 路径。
- 修复工作流编辑器在步骤重命名后丢失依赖的问题，并拒绝空 ID 和重复 ID。预设按名称精确查找，缺失时明确报错，不再替换为无关预设。
- 修复使用处理器别名（如 `transcode`、`upload`）的工作流步骤在 Web 界面中不显示设置和名称的问题。

## 弹幕

- 新增全局、平台、模板和主播级统计配置，可调整排行长度、时间线精度、跟踪容量和额外停用词。可关闭统计并继续保留弹幕文件。详见[弹幕统计](../getting-started/configuration.md)。
- 新增约每分钟一次的实时统计快照，重启后恢复已保存计数。长时间录制会降低时间线精度，不再丢弃早期活动。
- 新增平均消息速率、互动人数估计、聊天与礼物总量、送礼者和礼物排行，以及可展开的活跃用户榜。礼物图表仅在平台上报礼物时显示；互动人数估计误差通常约为 2%。
- 修复高频词计数虚高，并用 `≈` 标记估计值。中日文消息使用分词，不再将整句计为一个词。
- 修复活动图表把十秒计数显示为每分钟速率的问题。峰值和平均值使用正确速率，平均值覆盖整场会话，无活动时段显示为零。
- 修复连接失败后弹幕采集永久停止的问题。录制期间持续重连并保留统计，长时间断连会显示在系统健康页。
- 修复弹幕失败阻塞后处理的问题。中断的弹幕文件会完成写入并登记；被丢弃视频分段的弹幕文件也会从会话列表移除。
- 修复队列中的最后消息在关闭时丢失或被分到下一段的问题。并发停止请求和替换采集器等待同一个完成结果，避免采集器重叠运行。
- 修复新文件中的无效 XML 字符和头部注释；旧文件不会自动修复。MCP 分页保留完整 UTF-8 字符，并拒绝无效编码或无法推进读取的限制值。

## 配置

- 修复哔哩哔哩和抖音表单为未修改选项保存覆盖值的问题。继承设置继续继承，平台默认值正确显示。
- 两种时间过滤器编辑器新增时区选择。规则匹配和唤醒使用一致的跨夜、夏令时边界，包括重复小时；编辑保留已存时区，备份 schema 0.1.8 明确导出时区。
- 修复无效全局、平台设置被保存的问题。保存前校验类型、负值和溢出，同时保留受支持的零值、默认值含义。平台编辑不能更改 URL 查找所用的标准名称。
- 修复代理用户名、密码包含百分号、空格、Unicode 或 URL 分隔符时的处理。下载诊断不再包含代理 URL。
- 修复备份导入中的账号邮箱冲突。交换邮箱和复用已释放地址不受输入顺序影响，冲突在修改配置前被拒绝。
- 修复并发数据库操作丢失结果、重复扣减媒体大小，以及凭据刷新覆盖模板编辑的问题。更新失败时回滚相关改动。
- 修复全新独立数据库的录制目录初始化，使用 `OUTPUT_DIR`，未设置时使用转为绝对路径的 `./output`。已有数据库保留保存的目录。启动输出探测与录制尝试使用相同的目录分组。详见[输出根探测](../operations/storage.md)。

## 通知

- 修复管道开始、完成和失败通知未发送的问题。
- 修复事件历史中输出路径、GPU 和百度网盘重新登录告警的预览仅显示事件名称的问题，现会显示相关路径或错误。下载被拒绝、凭据失效和系统关闭事件也会显示原因。
- 邮件投递复用 SMTP 连接。渠道重载后，已接收的通知仍发往原目标，持续存在的渠道保留失败历史。
- 修复队列容量检查、被移出队列通知的重试取消，以及配置定义渠道的失败投递记录。重试不会向已成功的渠道重复发送。
- 修复 Web Push 退避状态和载荷大小检查。队列已满或不可用时，所有优先级的新事件都会丢弃并计数，不会重放；事件历史和其他渠道独立运行。详见[投递限制](../concepts/notifications.md)。
- 外部渠道新增有上限的投递超时和重试等待。错误报告失败类别或 HTTP 状态，不包含携带凭据的 URL 或响应正文。
- 修复 Telegram 消息中名称、标题和错误的特殊字符格式化，截断时保留完整 Unicode 字符。不支持的格式模式返回配置错误。
- 统一渠道启用、优先级检查和单次投递内的本地化渲染。渠道重载失败时保留当前配置。详见[通知接口](../concepts/notifications.md)。

## 认证与 API

- 新增账号和来源地址登录限流，返回 HTTP 429 和 `Retry-After`；密码校验并发有上限。反向代理后的来源限制按代理地址计算。详见[登录限流](../reference/environment.md#登录限流)。
- 修复并发登录清除其他尝试失败计数的问题。认证失败不透露账号是否存在，只有密码正确后才披露账号禁用状态。
- 修复刷新令牌轮换，最多签发一个替代令牌，数据库写入失败时保留原令牌。退出登录、禁用账号和修改密码后，已撤销会话无法复用。下载、日志 WebSocket 和日志归档授权会重新校验凭据。
- `AUTH_DISABLED=true` 时限制浏览器来源和 Host 头。额外本地来源可通过 `API_CORS_ORIGINS` 配置；启用认证时行为不变。
- 资源创建和模板、任务预设克隆改为返回 HTTP 201。OpenAPI 补充会话分段、模板克隆及浏览器 Web Push 操作；不可用的任务进度返回 `null`，不再显示为零。
- 媒体内容请求新增 `download=1`，以附件方式下载。媒体和流相关路由优先使用 Authorization 头，仅在其缺失时使用查询令牌。下载、日志 WebSocket、流代理和日志路由需要完整权限的 API 密钥。
- 任务、会话、产物、通知和预设搜索按字面匹配 `%`、`_` 和反斜杠。详见[搜索行为](../api/index.md)。
- URL 解析和会话删除批次超过 100 项时，在处理前拒绝。登录设备描述限制为 256 个 Unicode 字符，API 错误不再包含内部数据库或凭据诊断。
- 修复 Web 请求转发的标识和 URL 值。拒绝无效标识，正确编码保留字符。
- 修复凭据刷新，使 Cookie 和令牌原子保存。对象不存在或正在删除时拒绝刷新，写入失败保留原凭据。
- 从应用日志、浏览器诊断和通知调试输出中移除凭据及私有目标地址。BaiduPCS-Go 登录改用受保护的临时配置和标准输入，不再通过进程参数传递凭据。详见[凭据处理](../operations/security.md)。

## Web 界面

- 同源和跨域 Web 部署的录制下载均直接流式写入磁盘。桌面端操作改为在文件夹中显示已有录制。
- 修复退出登录后的账号缓存残留，避免下一个用户看到前一会话的数据。会话过期后跳转登录，登录后返回原页面；续期时的临时服务故障会保留当前会话并重试。
- 修复令牌刷新时传输进度中断。取消任务后仪表盘处理计数及时更新，录制中的实时计数保持一致。
- 减少重复页面加载和轮询，后台标签页暂停更新，任务日志仅刷新新增内容。实时日志分批渲染，并在会话续期后重连。
- 减少配置、工作流、导入摘要和时间安排编辑器的不必要重绘。
- 修复数字字段和斗鱼 CDN 选择清空后恢复旧值的问题，空字段显示继承值或默认值。仅接受整数的设置在表单中校验。
- 修复可编辑列表删除行后焦点或值错位的问题。空自定义标签在命名前保持独立。
- 修复原始 JSON 编辑器在每次输入后重新排版的问题。不完整文本可继续编辑，校验错误单独显示。
- 修复窗口焦点变化后丢失通知订阅修改的问题。哔哩哔哩二维码登录在二维码过期后停止轮询。
- 修复搜索、筛选和翻页后隐藏条目仍保持选中的问题。批量操作只针对当前选择。
- 修复损坏的已存设置导致整个平台或模板列表加载失败的问题。无效 URL 搜索、筛选参数单独忽略。
- 弹幕统计不可用、管道不存在或无法访问时，显示明确的空状态或错误。会话时间线在详情缺失时仍能识别已知事件。
- 恢复通知、预设卡片配色，修复切换预设或明暗主题后色块未更新的问题。
- 改进媒体卡片，显示文件类型、名称、路径、大小和会话。类型筛选及汇总覆盖整个文件库，并跟随搜索条件。
- 为图标按钮添加无障碍名称，时间安排控件和备份导入选项支持键盘操作。
- 补全相关对话框、播放器控件、卡片、计数、校验错误、日期、时间和时长的翻译。
- 新增侧边栏账号菜单，集中提供 API 密钥、账号设置、修改密码和退出登录入口。
- 修复日志文件下载失败时提示未翻译或为空的问题。
- 预设编辑器为所有处理器提供**恢复默认值**，替换已修改的配置前会先确认。
- 侧边栏通知红点在有新的严重事件时以动画出现，查看后淡出消失。
- 主播列表打开时直接显示主播卡片，仪表盘立即显示系统和管道概况，不再先显示占位内容、几秒后才填充。Web 界面首次加载时需要下载的内容也更少。
- 录制进行中时，显示实时录制的页面占用的处理器资源大幅降低；同时录制较多时，界面依然流畅，笔记本也不易发热。
- 修复通过 Cloudflare 访问且开启 Rocket Loader 时，打开 Web 界面会短暂闪现错误配色的问题。明暗模式和自定义主题现在从第一帧起即正确显示。
- 手机和窄窗口下的导航菜单现在点按即开、关闭同样迅速，滑动流畅，主播列表等长页面也不再卡顿。关闭后键盘焦点回到菜单按钮。

## 监控与维护

- 健康检查在组件状态未知时报告降级。文件系统采样缓慢时保留旧值并标记为过时或降级，不阻塞其他探测或不断创建任务。详见[健康监控](../operations/monitoring.md)。
- 应用日志默认限制为每文件 16 MiB、共 16 个文件，共享目录的实例协调轮转。启动时执行保留清理，超大记录标记为截断。详见[日志保留](../operations/monitoring.md#日志)。
- 日志归档通过有界缓冲流式生成 ZIP64，最多两个并发下载，每个归档最多 10,000 个文件。超额请求返回 HTTP 429，读取或压缩失败时终止下载。
- 日志初始化失败返回错误，不再触发 panic。重定向控制台日志省略 ANSI 颜色，无订阅者时跳过实时日志格式化。启动耗时保留 I/O、引擎发现和总体测量。
- SQLite 连接池共用建议的 64 MiB 私有页缓存额度，其中读取连接 56 MiB、写入连接 8 MiB；这不是进程内存硬上限。详见 [SQLite 内存预算](../operations/monitoring.md#sqlite-内存预算)。
- Vacuum 调度检查实际录制，只在获准执行期间暂停新录制启动。缓慢的文件系统预检查不会持有录制启动锁。
- 任务列表和导出使用批量关联查询，配置刷新采用有界并发，并缓存已解析的过滤规则和短期配置读取结果。
- 合并服务生命周期、仓库写入、导入持久化和处理器结果逻辑。移除未使用的依赖功能、重复模型、闲置辅助方法及未接入的 Prometheus 导出器。JSON 健康接口和 Web Push 计数器继续可用。

## 部署与桌面端

- HTTPS 反向代理传递的协议用于自动设置安全登录 Cookie。`COOKIE_SECURE` 仍可覆盖自动判断；使用明文 HTTP 的生产部署会记录警告。
- Web 容器改以普通账号而非 `root` 运行应用服务，并为所有响应添加 `X-Content-Type-Options` 和 `Referrer-Policy` 响应头；如果反向代理已添加这些响应头，请只保留一处。自行构建镜像时，不再打包 Web 源码目录中遗留的本地数据库文件。
- 新增可选 Watchtower 自动更新，通过 `docker compose --profile autoupdate up -d` 启用，使用无需认证的 `/api/health/idle` 检查。需要可变镜像标签，空闲检查后才开始的录制仍可能中断；自动升级应保留备份。详见[自动更新](../operations/upgrading.md#自动更新-watchtower)。
- 安装脚本根据系统语言或 `SREC_LANG` 选择中英文，检查下载内容，并在无法安全生成密钥时停止。
- 修复内置 systemd 单元的权限、状态与日志目录、环境加载和关闭等待。新数据库使用 `/var/lib/rust-srec/output`，已有数据库保留保存的目录。录制文件可由服务账号及其用户组读取。详见 [systemd 安装](../getting-started/installation.md#systemd-服务-linux)。
- 桌面端退出前会完成录制收尾，包括启动期间退出及 macOS 菜单、Dock 退出，最长等待一分钟。通过 Dock 退出或注销时，窗口在清理期间可能无响应。
- Linux 和 macOS 最小化到托盘改用窗口事件，不再持续轮询。
- 防止桌面端和独立后端同时使用同一个录制数据库，修复桌面端首次启动的 SQLite 锁冲突。
- 新增桌面启动恢复界面，说明数据库锁定、权限错误、存储已满或数据库损坏等问题，并提供复制诊断及打开数据、日志目录的入口。
