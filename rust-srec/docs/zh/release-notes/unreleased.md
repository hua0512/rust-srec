# 更新日志

## `unreleased`

## 新增功能

- **会话页面**：观看录像时，录制的弹幕会按视频时间显示在画面上。播放器中的**弹幕设置**面板可以屏蔽弹幕类型，调整不透明度、字号、速度和显示区域，合并重复弹幕，悬停时暂停弹幕，在进度条上方显示弹幕热度，并屏蔽关键词或用户。设置会被记住，大型弹幕文件加载时页面不会卡顿。参见[弹幕录制](../guides/danmu.md#观看带弹幕的录像)。
- **播放器页面**：播放直播时，弹幕会实时显示在画面上，同样可以用弹幕按钮和**弹幕设置**控制。网格中的每个播放器显示各自直播的弹幕，隐藏弹幕时不会接收弹幕。参见[观看带弹幕的直播](../guides/danmu.md#观看带弹幕的直播)。
- **Twitch**：新增平台设置 **允许 H.265 (HEVC)** 和 **允许 AV1**，可录制部分频道仅以这些编码提供的更高画质。两项默认关闭，未开启时录制仍为 H.264。详见 [Twitch](https://docs.srec.rs/zh/platforms/twitch)。

## 修复

- **预设**：打开使用 NVIDIA（NVENC）编码的已保存重封装预设或工作流步骤时，编码预设可能被改为 Medium，下次保存时会保留这一更改。现在会保留已保存的预设。
- **工作流**：在预设步骤中使用**分离并编辑**时，现在总是以预设保存的设置为准。此前在步骤中显示的预设设置看似只读，但通过键盘做出的修改会在分离时被悄悄复制到步骤中。
- **主播页面**：某个主播保存的设置无法读取时，不会再导致整个主播列表无法加载。这些设置会显示为未配置。
- **FLV 录制**：使用 Mesio 引擎录制的文件现在会将创建者记录为 Mesio（此前为过时的版本号），并记录实际的数据大小（此前为 0），媒体工具显示的文件信息因此准确。
- **FLV 录制**：使用 Mesio 引擎并开启 **修复 FLV 流** 时，直播中途重新推流（例如主播开启了直播延迟）后，录制可能变成一个超长文件，播放器显示时长为 0 秒，也不会按时长限制分段。现在录制在这类重新推流后会继续正常计时，并按设置分段。
- **FLV 录制**：直播流未提供文件信息时，浏览器播放器现在也能显示录制文件的时长并拖动进度。此项适用于使用 Mesio 引擎并开启 **修复 FLV 流** 的录制；FFmpeg 和 Streamlink 录制不受影响。
- **FLV 录制**：使用 Mesio 引擎并开启 **修复 FLV 流** 时，直播流在画面开始前发送多组相互冲突的设置，录制文件现在也可以正常复制和转换。此前复制或转换这类文件时，可能沿用较早的设置，而不是直播流最终采用的设置。FFmpeg 和 Streamlink 录制不受影响。
- **Huya**：普通弹幕现在不再记录颜色，转换的字幕和烧录的视频中会显示为白色，而不是蓝色。平台本身带颜色的弹幕仍保留原颜色。更新前录制的弹幕文件仍为蓝色。
- **Twitch**：刚开播或刚下播、暂时无法播放的频道现在会显示为未开播，不再导致开播检测报错。Twitch 拒绝播放时，会显示 Twitch 返回的错误信息。
- **Twitch**：不存在的频道现在会显示为未找到，被封禁的频道显示为已封禁，不再在每次开播检测时报数据错误。

- **Twitcasting**：平台设置中的 **直播密码** 现在可以解锁带密码的直播。此前只有加在主播 URL 中的密码（`?password=...`）有效；URL 中的密码仍然优先。
- **YouTube**：指向已上传或已结束视频的链接现在会显示为未开播，而不是正在直播，不会再在每次开播检测时被重复录制。正在进行的直播不受影响。
