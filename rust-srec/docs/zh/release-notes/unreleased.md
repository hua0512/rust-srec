# 更新日志

## `unreleased`

## 新增功能

- **MPEG-DASH 录制：** Mesio 现在可以录制 MPEG-DASH（`.mpd`）流，包括直播和已结束的流。分开传输的视频和音频会合并为一个 MP4 文件。可在 Mesio 引擎新增的 **DASH 调优** 选项卡中选择视频和音频质量、音频语言、直播录制起点以及下载限制；在**首选格式**中添加 `dash`，即可在平台提供 DASH 时优先使用。不支持 DRM 加密的流，网页播放器也无法播放 DASH 流。详见 [MPEG-DASH 录制](../concepts/engines.md#mpeg-dash)。

## 录制与恢复

- 修复 Mesio 在直播地址无法看出是 HLS 还是 FLV 时拒绝录制的问题，现在会使用平台报告的格式。
- HLS 流的分片全部下载失败时，Mesio 现在会报告具体原因（例如 HTTP 状态码或网络错误），而不是“流为空”。fMP4 流的初始化分片无法下载时，Mesio 会停止下载依赖它、只会被丢弃的媒体，因此这类尝试会更快结束。

## Web 界面

- 修复在笔记本和桌面窗口尺寸下，侧边栏占去部分宽度后，卡片、编辑器和详情页内容溢出或被挤压的问题。卡片列表现在按页面实际可用宽度排列列数，页面标题栏中的按钮会自动换行，过长的名称、标题、URL 和配置项以“…”截断，悬停可查看完整内容。
- 修复模板中的 Mesio 引擎覆盖。所有 HLS 与 FLV 设置以及 **修复 FLV 流**、**修复 HLS 不连续性**、**修复 DASH 流** 开关现在都会显示所继承的引擎设置，并可选择沿用引擎设置、使用默认值或自定义值；此前未设置的开关显示为关闭，HLS 设置需先开启 **修复 HLS 不连续性** 才能编辑，且包含重置设置的模板无法保存。模板中不再为 **最大停顿时间** 和 **点播分段超时** 提供 **已禁用** 选项，因为模板从来无法真正关闭它们，请在引擎中设置。
- Mesio 引擎的 **HLS 调优** 标签页在关闭 **修复 HLS 不连续性** 时不再锁定，因为其中的下载设置始终生效。
- 保存 Mesio 引擎或模板时不再删除表单未显示的 HLS 设置（例如通过 API 设置的项）；缺口策略、码率变体或 DASH 质量选项中被清空的数字现在会提示错误，而不是保存为 0。
- 引擎设置页改为与代理相同的列表形式，显示每个引擎的类型、已安装版本和状态，并在旁边提供 **配置** 按钮。
