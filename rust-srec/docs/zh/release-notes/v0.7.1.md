# 更新日志

## `v0.7.1`

本次更新改进 Windows 便携版的桌面通知，并在通知测试失败时显示错误信息。

## 桌面通知

- Windows 便携版现在会在发送通知前，为当前用户注册通知名称和图标，无需运行安装程序或取得管理员权限。这解决了从未安装过 rust-srec 的系统上，因缺少应用标识而导致 **测试** 按钮和常规事件通知无法弹出通知的问题。
- Windows 通知中显示的应用名称改为 **Rust-Srec**。内部应用标识和软件包名称保持不变。
- 桌面通知的 **测试** 按钮现在会显示注册和提交失败的错误信息，不再静默丢弃错误。测试通知与常规事件通知使用相同的发送路径。

## 升级前须知

- 从 v0.7.0 升级无需迁移配置或数据库。
- Windows 通知设置和勿扰模式仍然生效。提交成功不代表一定会显示横幅。更新后，可通过 **通知 → 桌面通知 → 测试** 检查当前系统的通知表现。
- 应用退出后，通知注册信息和图标仍保留在当前用户的配置目录中，因此移动便携版文件夹不会改变通知图标的位置。
